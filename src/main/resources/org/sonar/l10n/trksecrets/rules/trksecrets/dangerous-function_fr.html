eval, exec, system et les appels similaires peuvent conduire à l'exécution de code à distance lorsqu'ils reçoivent des données non fiables.

Exemple de code non conforme

os.system(command)

Solution conforme

Utilisez une API sûre avec une liste d'arguments explicite.

Remarques

Inactive par défaut. Python uniquement.
