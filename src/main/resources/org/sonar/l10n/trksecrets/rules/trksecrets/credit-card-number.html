A value of 13 to 19 digits that passes the Luhn check may be a payment card number.

Why is this an issue?

Credentials must never appear in clear text in source code: use a credentials store (such as Vault or credstash) and refer to secrets by identifier.

Noncompliant code example

card = "4111111111111111"

Compliant solution

Use a tokenization service.

Notes

Inactive by default: any long number can pass the Luhn check.
