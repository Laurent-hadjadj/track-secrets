Une valeur de 13 à 19 chiffres qui passe le contrôle de Luhn peut être un numéro de carte bancaire.

Pourquoi est-ce un problème ?

Un identifiant ne doit jamais apparaître en clair dans le code source : utilisez un coffre de secrets (comme Vault ou credstash) et référencez les secrets par leur identifiant.

Exemple de code non conforme

card = "4111111111111111"

Solution conforme

Utilisez un service de tokenisation.

Remarques

Inactive par défaut : n'importe quel long nombre peut passer le contrôle de Luhn.
