Les URL de webhook de Slack, Hubspot et Twilio contiennent un chemin secret : toute personne qui le connaît peut publier des messages.

Pourquoi est-ce un problème ?

Un identifiant ne doit jamais apparaître en clair dans le code source : utilisez un coffre de secrets (comme Vault ou credstash) et référencez les secrets par leur identifiant.

Exemple de code non conforme

https://hooks.slack.com/services/T00000000/B00000000/XXXXXXXXXXXXXXXXXXXXXXXX

Solution conforme

Lisez l'URL depuis un coffre de secrets.
