Les magasins de clés, certificats, fichiers .env, .netrc, historiques de shell ou fichiers de mots de passe ne doivent pas être versionnés.

Pourquoi est-ce un problème ?

Un identifiant ne doit jamais apparaître en clair dans le code source : utilisez un coffre de secrets (comme Vault ou credstash) et référencez les secrets par leur identifiant.

Exemple de code non conforme

config/prod.env

Solution conforme

Ajoutez le fichier au .gitignore et fournissez un modèle.

Remarques

Inactive par défaut. Basée uniquement sur le nom du fichier.
