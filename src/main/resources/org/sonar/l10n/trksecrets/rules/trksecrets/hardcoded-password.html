A password written in clear text in the source code or in a configuration file is readable by everyone who can access the repository, its history, build artifacts or logs. It cannot be rotated without a new release.

Why is this an issue?

Credentials must never appear in clear text in source code: use a credentials store (such as Vault or credstash) and refer to secrets by identifier.

Noncompliant code example

db.password=Sup3rS3cret!

Compliant solution

db.password=${DB_PASSWORD}

Notes

Detected from the name of the key (password, passwd, pwd, pass). Values with more than one space (labels), placeholders and variables are ignored. In Java, Kotlin, C#, Python, JavaScript, TypeScript and PHP files the rule is skipped by default (property track.secrets.skipNativeOverlap) because the language analyzers already provide S2068.
