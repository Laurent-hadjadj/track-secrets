Tokens with a recognizable format (Slack, Stripe, SendGrid, Mailgun, Twilio, JWT, Terraform Cloud, HashiCorp Vault) are credentials.

Why is this an issue?

Credentials must never appear in clear text in source code: use a credentials store (such as Vault or credstash) and refer to secrets by identifier.

Noncompliant code example

stripe.key = "sk_live_0123456789abcdefghijklmn"

Compliant solution

stripe.key = ${STRIPE_KEY}

Notes

Complements sonar-text, which does not cover these formats.
