A private key committed to a repository must be considered compromised, even if it is deleted later: it remains in the history.

Why is this an issue?

Credentials must never appear in clear text in source code: use a credentials store (such as Vault or credstash) and refer to secrets by identifier.

Noncompliant code example

-----BEGIN RSA PRIVATE KEY-----

Compliant solution

Store the key in a vault or a key store and reference it by identifier.
