A long string mixing letters and digits with a high Shannon entropy looks like randomly generated cryptographic material.

Why is this an issue?

Credentials must never appear in clear text in source code: use a credentials store (such as Vault or credstash) and refer to secrets by identifier.

Noncompliant code example

seed = "x9Fq2LmZ7vB1nTa8KcR4wYd6"

Compliant solution

seed = ${SEED}

Notes

The threshold (default 4.5 bits per character) is set with track.secrets.entropy.threshold. Review the results manually: hashes and identifiers may be reported.
