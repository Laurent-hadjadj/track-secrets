Une URL de la forme https://utilisateur:motdepasse@hôte dans pip.conf expose les identifiants du dépôt.

Pourquoi est-ce un problème ?

Un identifiant ne doit jamais apparaître en clair dans le code source : utilisez un coffre de secrets (comme Vault ou credstash) et référencez les secrets par leur identifiant.

Exemple de code non conforme

index-url = https://user:s3cret@pypi.example/simple

Solution conforme

Utilisez un trousseau (keyring) ou une variable d'environnement.
