Autoriser toutes les origines, tous les en-têtes ou les identifiants permet à n'importe quel site web d'appeler l'API au nom d'un utilisateur.

Exemple de code non conforme

ResourceOptions(allow_credentials=True, allow_headers="*")

Solution conforme

Listez explicitement les origines et les en-têtes.

Remarques

Inactive par défaut. Python uniquement.
