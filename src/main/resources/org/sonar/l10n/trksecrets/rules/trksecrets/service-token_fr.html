Les jetons à format reconnaissable (Slack, Stripe, SendGrid, Mailgun, Twilio, JWT, Terraform Cloud, HashiCorp Vault) sont des identifiants.

Pourquoi est-ce un problème ?

Un identifiant ne doit jamais apparaître en clair dans le code source : utilisez un coffre de secrets (comme Vault ou credstash) et référencez les secrets par leur identifiant.

Exemple de code non conforme

stripe.key = "sk_live_0123456789abcdefghijklmn"

Solution conforme

stripe.key = ${STRIPE_KEY}

Remarques

Complète sonar-text, qui ne couvre pas ces formats.
