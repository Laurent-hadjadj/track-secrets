API keys and access tokens give access to a service on behalf of their owner. Once committed, they must be considered compromised.

Why is this an issue?

Credentials must never appear in clear text in source code: use a credentials store (such as Vault or credstash) and refer to secrets by identifier.

Noncompliant code example

api_key: "k8Jd92LmQp0xZvB3nTa7"

Compliant solution

api_key: ${API_KEY}

Notes

Detected from key names ending in key or token, with a value of at least 16 characters without spaces that does not resemble the key name.
