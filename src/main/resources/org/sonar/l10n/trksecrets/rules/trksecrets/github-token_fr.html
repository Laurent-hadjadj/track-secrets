Les jetons d'accès personnels, OAuth, d'installation et à permissions fines de GitHub donnent accès aux dépôts. Révoquez tout jeton trouvé dans le code.

Pourquoi est-ce un problème ?

Un identifiant ne doit jamais apparaître en clair dans le code source : utilisez un coffre de secrets (comme Vault ou credstash) et référencez les secrets par leur identifiant.

Exemple de code non conforme

token = "ghp_0123456789abcdefghijklmnopqrstuvwxyz"

Solution conforme

token = ${GITHUB_TOKEN}

Remarques

Inactive par défaut : sonar-text couvre déjà les jetons GitHub dans SonarQube.
