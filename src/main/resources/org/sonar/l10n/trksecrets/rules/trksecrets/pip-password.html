A URL of the form https://user:password@host in pip.conf exposes the repository credentials.

Why is this an issue?

Credentials must never appear in clear text in source code: use a credentials store (such as Vault or credstash) and refer to secrets by identifier.

Noncompliant code example

index-url = https://user:s3cret@pypi.example/simple

Compliant solution

Use a keyring or an environment variable.
