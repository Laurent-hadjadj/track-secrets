GitHub personal access, OAuth, installation and fine-grained tokens give access to repositories. Revoke any token found in code.

Why is this an issue?

Credentials must never appear in clear text in source code: use a credentials store (such as Vault or credstash) and refer to secrets by identifier.

Noncompliant code example

token = "ghp_0123456789abcdefghijklmnopqrstuvwxyz"

Compliant solution

token = ${GITHUB_TOKEN}

Notes

Inactive by default: sonar-text already covers GitHub tokens in SonarQube.
