Key stores, certificates, .env files, .netrc, shell histories or password files should not be versioned.

Why is this an issue?

Credentials must never appear in clear text in source code: use a credentials store (such as Vault or credstash) and refer to secrets by identifier.

Noncompliant code example

config/prod.env

Compliant solution

Add the file to .gitignore and provide a template.

Notes

Inactive by default. Based on the file name only.
