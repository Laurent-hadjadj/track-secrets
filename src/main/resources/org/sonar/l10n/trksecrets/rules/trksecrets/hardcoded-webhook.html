Slack, Hubspot and Twilio webhook URLs contain a secret path: anyone who knows it can post messages.

Why is this an issue?

Credentials must never appear in clear text in source code: use a credentials store (such as Vault or credstash) and refer to secrets by identifier.

Noncompliant code example

https://hooks.slack.com/services/T00000000/B00000000/XXXXXXXXXXXXXXXXXXXXXXXX

Compliant solution

Read the URL from a secret store.
