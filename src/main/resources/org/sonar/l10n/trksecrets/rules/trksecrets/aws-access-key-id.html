An AWS Access Key ID, together with its secret key, grants access to AWS resources.

Why is this an issue?

Credentials must never appear in clear text in source code: use a credentials store (such as Vault or credstash) and refer to secrets by identifier.

Noncompliant code example

aws_access_key_id = AKIAIOSFODNN7EXAMPLE

Compliant solution

Use an IAM role or AWS_ACCESS_KEY_ID from the environment.

Notes

Inactive by default: sonar-text already covers AWS credentials in SonarQube. Activate it only if sonar-text is not installed.
