Le champ auth d'un fichier .dockercfg ou config.json est l'encodage base64 de utilisateur:mot de passe.

Pourquoi est-ce un problème ?

Un identifiant ne doit jamais apparaître en clair dans le code source : utilisez un coffre de secrets (comme Vault ou credstash) et référencez les secrets par leur identifiant.

Exemple de code non conforme

{"auths": {"registry.example": {"auth": "dXNlcjpwYXNz"}}}

Solution conforme

Utilisez un assistant d'identifiants (credential helper) ou un secret de l'intégration continue.
