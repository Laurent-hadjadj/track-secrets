Un identifiant de clé d'accès AWS (Access Key ID), associé à sa clé secrète, donne accès aux ressources AWS.

Pourquoi est-ce un problème ?

Un identifiant ne doit jamais apparaître en clair dans le code source : utilisez un coffre de secrets (comme Vault ou credstash) et référencez les secrets par leur identifiant.

Exemple de code non conforme

aws_access_key_id = AKIAIOSFODNN7EXAMPLE

Solution conforme

Utilisez un rôle IAM ou la variable d'environnement AWS_ACCESS_KEY_ID.

Remarques

Inactive par défaut : sonar-text couvre déjà les identifiants AWS dans SonarQube. Ne l'activez que si sonar-text n'est pas installé.
