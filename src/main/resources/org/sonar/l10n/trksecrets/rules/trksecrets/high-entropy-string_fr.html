Une longue chaîne mêlant lettres et chiffres, avec une entropie de Shannon élevée, ressemble à un élément cryptographique généré aléatoirement.

Pourquoi est-ce un problème ?

Un identifiant ne doit jamais apparaître en clair dans le code source : utilisez un coffre de secrets (comme Vault ou credstash) et référencez les secrets par leur identifiant.

Exemple de code non conforme

seed = "x9Fq2LmZ7vB1nTa8KcR4wYd6"

Solution conforme

seed = ${SEED}

Remarques

Le seuil (4,5 bits par caractère par défaut) se règle avec track.secrets.entropy.threshold. Vérifiez les résultats manuellement : des empreintes (hash) et des identifiants peuvent être signalés.
