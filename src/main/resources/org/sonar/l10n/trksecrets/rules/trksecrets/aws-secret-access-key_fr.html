Une clé d'accès secrète AWS (Secret Access Key) permet de signer des requêtes vers AWS. Révoquez toute clé trouvée dans le code source.

Pourquoi est-ce un problème ?

Un identifiant ne doit jamais apparaître en clair dans le code source : utilisez un coffre de secrets (comme Vault ou credstash) et référencez les secrets par leur identifiant.

Exemple de code non conforme

aws_secret_access_key = wJalrXUtnFEMI/K7MDENG/bPxRfiCYEXAMPLEKEY

Solution conforme

Utilisez un rôle IAM ou un gestionnaire de secrets.

Remarques

Inactive par défaut : sonar-text couvre déjà les identifiants AWS dans SonarQube.
