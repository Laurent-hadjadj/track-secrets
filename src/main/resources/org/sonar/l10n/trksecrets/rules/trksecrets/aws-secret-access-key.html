An AWS Secret Access Key allows signing requests to AWS. Revoke any key found in source code.

Why is this an issue?

Credentials must never appear in clear text in source code: use a credentials store (such as Vault or credstash) and refer to secrets by identifier.

Noncompliant code example

aws_secret_access_key = wJalrXUtnFEMI/K7MDENG/bPxRfiCYEXAMPLEKEY

Compliant solution

Use an IAM role or a secret manager.
